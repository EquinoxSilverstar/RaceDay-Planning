# RaceDay Technical References

The RaceDay ERD, API endpoint plan and SQL database design are original work. The sources below support the external HTTP and SQL Server technical conventions referenced in the planning documents.

Internet Engineering Task Force (IETF) (2022) *RFC 9110: HTTP Semantics*. RFC 9110. Available at: https://www.rfc-editor.org/rfc/rfc9110.html (Accessed: 4 September 2026).

Internet Engineering Task Force (IETF) (2023) *RFC 9457: Problem Details for HTTP APIs*. RFC 9457. Available at: https://www.rfc-editor.org/rfc/rfc9457.html (Accessed: 4 September 2026).

Microsoft (2026) *Primary and foreign key constraints - SQL Server*. Available at: https://learn.microsoft.com/en-us/sql/relational-databases/tables/primary-and-foreign-key-constraints?view=sql-server-ver17 (Accessed: 4 September 2026).
